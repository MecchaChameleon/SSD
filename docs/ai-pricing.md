# AI 가격 추천 및 검증

제주 로컬타임 AI는 지역 수요를 추정하는 모델과 최종 가격을 결정하는 정책을 분리합니다. 수요예측 성능과 가격 정책의 판매 효과도 각각 다른 지표로 평가합니다.

## 현재 가격 추천 구조

현재 가격 서버는 `artifacts/daily_demand_profile.json`에 저장된 일별 EBM 수요 프로파일을 우선 사용합니다. 수요 프로파일에는 2023-06-02~2026-05-31의 제주 일별 유동인구 51,300행을 기반으로 한 학습 정보가 기록되어 있습니다.

가격 정책은 다음 입력을 결합합니다.

| 입력 | 반영 내용 |
|---|---|
| 지역 수요 | 해당 지역의 수요 백분위 |
| 잔여 재고 | 전체 수량 대비 남은 수량 |
| 판매속도 | 최근 재고 변화 |
| 경과 시간 | 전체 판매 가능 시간 대비 지난 시간 |
| 날씨 | 강수량, 풍속, 기온과 야외상품 여부 |
| 달력·시간대 | 주말, 피크시간 |

계산된 정책 압력을 판매자 최저가~정상가 범위의 위치로 변환하고, 수익 우선·균형·재고 처리 우선의 가격안을 제공합니다. 정책 내부의 압력 수치를 실제 할인율과 동일하게 해석하지 않습니다.

추천 근거는 지역 수요, 재고, 시간, 날씨 등이 가격에 미치는 영향을 정책식에서 계산한 것입니다. 이를 학습모델의 SHAP 설명이나 실제 구매확률로 표현하지 않습니다.

## 수요예측 비교 실험

현재 프로파일과 별도로 XGBoost 수요예측 비교 실험을 진행했습니다. 아래 수치는 **XGBoost 실험 결과**이며 현재 EBM 가격 서버의 성능 수치가 아닙니다.

- 학습 데이터 범위: 2023-06-02~2026-05-31
- 분리 방식: 시간순 학습·검증·테스트
- 최종 테스트: 2026-03-03~2026-05-31
- 평가 단위: 원본 인구집단 행의 예측치를 읍면동×일로 합산

| 예측 방식 | MAE | WAPE | R² |
|---|---:|---:|---:|
| 전월 일평균 | 3,328.1 | 24.83% | 0.7848 |
| 최근 4회 동일요일 평균 | 2,741.2 | 20.45% | 0.8400 |
| 공공데이터 기반 XGBoost | 2,284.5 | 17.04% | 0.9085 |

XGBoost의 MAE는 전월 일평균 대비 31.4%, 최근 동일요일 평균 대비 16.7% 낮았습니다. 이 결과는 유동인구 추정 성능을 설명하며, 구매 전환이나 매출 증가를 직접 입증하지 않습니다.

근거: [수요예측 성능표](https://github.com/MecchaChameleon/SSD_AI/blob/main/docs/PPT_XGB_성능표.md), [검증 원본 JSON](https://github.com/MecchaChameleon/SSD_AI/blob/main/artifacts/xgb_daily_validation_report.json).

## 가격 정책 합성실험

실제 거래 이력이 충분하지 않은 초기 단계에서 정책을 비교하기 위해 5개 합성 페르소나를 사용했습니다. 180일·1,800개 상품 시나리오에서 전략별 54,623명의 합성 사용자 후보를 생성했고, 시간순 앞 60%에서 정책을 보정한 뒤 뒤 40%에서 평가했습니다. 평가구간은 전략별 합성 사용자 22,003명입니다.

다음은 **균형형 규칙정책의 가중치 조절 전후**를 동일 평가구간에서 비교한 결과입니다.

| 지표 | 조절 전 | 조절 후 | 변화 |
|---|---:|---:|---:|
| 매출 | 826,721,900원 | 841,724,800원 | +1.81% |
| 폐기 반영 순이익 | 505,765,400원 | 520,768,300원 | +2.97% |
| 재고 소진율 | 67.90% | 75.58% | +7.68%p |

금액은 합성 시나리오의 합산 결과입니다. 실제 매출, 실제 고객 전환율 또는 상용 서비스의 개선 실적으로 해석하지 않습니다. 비교 대상 역시 고정가가 아닌 조절 전 규칙정책입니다.

같은 합성실험에서 조절 후 균형형 규칙은 균형형 LinUCB의 매출 99.5%, 폐기 반영 순이익 99.2% 수준이었습니다. LinUCB는 비교 실험용 정책이며 현재 가격 서버의 운영 정책은 규칙 기반입니다.

근거: [가격 정책 상세 설명](https://github.com/MecchaChameleon/SSD_AI/blob/main/docs/PPT_가격정책_어펜딕스.md), [가중치 보정 결과](https://github.com/MecchaChameleon/SSD_AI/blob/main/artifacts/persona_rule_calibration.json), [시뮬레이션 안내](https://github.com/MecchaChameleon/SSD_AI/tree/main/simulation).

## 운영 데이터 축적 이후

실제 노출·제시가격·구매/미구매·잔여재고 데이터를 연결해 구매확률과 가격탄력성을 보정하는 것을 다음 단계로 둡니다. 학습형 정책은 오프라인 검증과 제한적 실험을 거쳐 적용하고, 판매자 최저가와 가격 변경 주기 등은 모델 외부 제약으로 유지합니다.
